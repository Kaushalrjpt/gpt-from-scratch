# GPT from Scratch

This project focuses on understanding how GPT (Generative Pre-trained Transformer) models work by building a small language model from scratch using Python and PyTorch.

I'm following Andrej Karpathy's *Let's build GPT from scratch* tutorial as a learning reference while implementing and experimenting with the underlying concepts.

## Learning Objectives

- Understand tokenisation and character-level language modelling.
- Learn how embeddings represent tokens.
- Understand self-attention and transformer architecture.
- Implement a decoder-only Transformer.
- Train a small GPT model and experiment with text generation.

## Tech Stack

- Python
- PyTorch
- Jupyter Notebook
